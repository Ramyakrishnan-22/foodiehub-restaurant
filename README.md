# FoodieHub – Restaurant Website

## About the Project
FoodieHub is a responsive vegetarian restaurant website designed to provide customers with an easy and user-friendly food browsing and ordering experience.

## Features
- Responsive design for mobile, tablet and desktop
- Food menu with categories
- Food item cards with prices and images
- Add-to-cart functionality
- Cart total calculation
- Order confirmation interface
- Contact form

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
```text
foodiehub/
├── index.html
├── style.css
├── script.js
└── images/
```

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
